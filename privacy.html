Kebijakan Privasi

Terakhir diperbarui:

Data yang kami kumpulkan

NexaKit Pro menyimpan username, password (terenkripsi lewat Supabase Auth), dan data profil opsional seperti nama tampilan serta foto profil yang kamu unggah sendiri.

Cara kami menggunakan link/file yang kamu masukkan

  • Link (TikTok, Instagram, YouTube, dll.) diteruskan ke penyedia API pihak ketiga hanya untuk mengambil hasil unduhan — tidak disimpan permanen di server kami.
  • Gambar yang kamu unggah untuk tools seperti Remove Background, Foto To Link, atau Fake Lobby diproses lewat API pihak ketiga dan/atau ImgBB sesuai kebutuhan tool tersebut.
  • Riwayat download TikTok disimpan di perangkatmu sendiri (localStorage), bukan di server.

Pihak ketiga

Autentikasi ditangani oleh Supabase. Beberapa tools memanggil API downloader/generator pihak ketiga untuk memproses permintaanmu.

Kontak

Ada pertanyaan soal privasi datamu? Hubungi kami lewat tombol "Report Bug / Saran" di dalam aplikasi.
